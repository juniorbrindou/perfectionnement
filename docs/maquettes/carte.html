Face des cartes

Ton modèle reproduit avec les vraies données du jeu. Les cartes ont le même rapport que le dos (1 : 1,87). En doré dans la légende, ce qui change d’une carte à l’autre. La question et les réponses rétrécissent un peu quand elles sont longues, pour toujours tenir sur la carte.
